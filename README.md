# SIH98 ERP Backend

Backend foundation for a Smart India Hackathon ERP project covering student, teacher, hostel, fee, and administrator workflows.

## Current backend

- Express application setup
- MongoDB connection with Mongoose
- CORS and cookie middleware
- Environment-based configuration

## Tech stack

Node.js, Express, MongoDB, Mongoose, JWT, bcrypt, Cloudinary, Multer

## Run locally

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```
